## 🎬 5. QUY TRÌNH DEEP WORK DAVINCI RESOLVE TẠI `~/studio`

1. **Cấu trúc thư mục chuẩn tại `~/studio/`:**
   ```text
   ~/studio/
   ├── keyboard-shortcuts/     (Chứa file Sean_Kang_Shortcut_2025 Keys.txt)
   └── [YYYYMMDD]_[Client]_[Project]/
       ├── 01_Footage/         (Video thô quay từ máy)
       ├── 02_Audio/           (Nhạc nền, SFX, Voiceover)
       ├── 03_Graphics/        (Logo, ảnh PNG, icons)
       ├── 04_Exports/         (Video render v01, v02, Final)
       └── 05_Projects/        (File project .drp)
   ```
2. **Cụm phím thần tốc tay trái:**
   * **`Q`**: Xén gọn đầu clip (Ripple Trim Left).
   * **`W`**: Cắt đôi clip tại kim (Split Clip).
   * **`E`**: Xén gọn đuôi clip (Ripple Trim Right).
   * **`Alt + S`**: Thêm Serial Node chỉnh màu / **`Alt + O`**: Tạo Outside Node đảo vùng chọn.
3. **Chu kỳ Flow Pomodoro:**
   * Phím tắt Raycast: **`Ctrl + Option + Space`** (Bật / Tạm dừng).
   * Phím tắt Raycast: **`Ctrl + Option + S`** (Bỏ qua phiên / Chuyển sang Break).
   * 10 phút Break: Nhìn xa ngoài cửa sổ, uống nước, **Shadowboxing nhẹ nhàng 3 phút**.

## ⌨️ 6. QUY TRÌNH GTD TRONG DOOM EMACS

1. **Bắt việc nhanh:** Bất cứ lúc nào nảy ra việc vặt, bấm **`C-c <tab>`** (`langpn/org-capture-inbox`), gõ việc cần làm, bấm `C-c C-c`. Task tự chui vào `~/.org/gtd/inbox.org`.
2. **Xem Agenda mỗi sáng (08:35):** Bấm **`C-c SPC`** (`langpn/org-agenda`), xem 4 khối:
   * Block 1: Việc trong Inbox chưa xử lý.
   * Block 2: Lịch tuần.
   * Block 3: Việc đang làm (`NEXT`).
   * Block 4: Danh sách các dự án đang chạy (`Active Projects`).
3. **Bấm giờ làm việc (Clock-in):** Đặt con trỏ vào task DaVinci, bấm **`I`** để bấm giờ, bấm **`O`** khi nghỉ. Cột `%CLOCKSUM` là bằng chứng thực tế số giờ bạn đã cày.
